# MyPharmacy v59 — نسخة سحابية (Firebase)

البيانات الآن في Firestore (مشتركة بين كل الأجهزة)، وتسجيل الدخول عبر Firebase Auth، والاستضافة على Firebase Hosting. كل ذلك على الخطة المجانية Spark دون بطاقة دفع.

## خطوات النشر (حوالي 10 دقائق)

1. ادخل https://console.firebase.google.com ← **Add project** (يمكنك إيقاف Google Analytics).
2. **Build ← Authentication ← Get started ← Email/Password ← Enable**.
3. **Build ← Firestore Database ← Create database** (اختر أقرب منطقة، وضع Production).
4. **Project settings (⚙️) ← Your apps ← أيقونة الويب `</>`** ← سجّل التطبيق وانسخ `firebaseConfig`، ثم الصقه في `public/firebase-config.js`.
5. **Firestore ← Rules**: الصق محتوى `firestore.rules` واضغط **Publish**.
6. النشر (أحد الطريقين):
   - من الطرفية (تحتاج Node.js):
     ```
     npm i -g firebase-tools
     firebase login
     firebase use --add      # اختر مشروعك
     firebase deploy
     ```
   - أو من الموقع: **Build ← Hosting ← Get started** واتبع الخطوات.
7. افتح الرابط (`https://اسم-المشروع.web.app`) وسجّل الدخول فوراً باسم **manager** وكلمة سر **تختارها أنت** (6 أحرف فأكثر). أول دخول ينشئ حساب المدير بهذه الكلمة. افعل ذلك أولاً قبل مشاركة الرابط مع أحد.

بعدها أضف بقية المستخدمين من صفحة «المستخدمون والصلاحيات».

## نقل بيانات النسخة القديمة (v58)
في النسخة القديمة: إنشاء نسخة احتياطية (Backup) ← في النسخة الجديدة بعد الدخول كمدير: استرجاع (Restore). الدواء والمبيعات وغيرها تُنقل، أما حسابات المستخدمين فتُنشأ من جديد.

## ملاحظات مهمة
- **إعادة تعيين كلمة سر مستخدم آخر** (من شاشة تعديل المستخدم) تنشئ له حساب دخول جديداً داخلياً، وتنقطع جلساته على الأجهزة الأخرى. تغيير كلمة سرك أنت يتم من زر تغيير كلمة السر.
- **الصلاحيات** (مدير/مشرف/صيدلي) تُطبَّق داخل الواجهة؛ قواعد Firestore تتحقق فقط أن المستخدم مسجّل ومفعّل، ومن المدير فقط لإدارة المستخدمين.
- **حدود المجاني:** Firestore حتى 1 جيجابايت و50 ألف قراءة و20 ألف كتابة يوميًا. القراءات تزيد مع حجم البيانات عند كل فتح للتطبيق؛ إن اقتربت من الحد انتقل لخطة Blaze (تشمل نفس الحصة المجانية).
- صور إشعارات التحويل تُضغط وتُحفظ داخل السجل نفسه (لا نستخدم Cloud Storage لأنه يتطلب خطة مدفوعة).
- العمل دون إنترنت: القراءة تعمل من الكاش المحلي، والتعديلات تُرسل عند عودة الاتصال.
